CursorBubble · web-demo

De bubbel, speelbaar op je telefoon.

De echte app is een Windows-programma (WPF, .NET 8) en draait alleen op Windows 10/11. Deze pagina bouwt de bubbel na in de browser — dezelfde geometrie, dezelfde standaardinstellingen, dezelfde live preview — zodat je hem kunt bekijken en instellen zonder iets te downloaden.

Dit is een nabootsing, geen echte app. Segmenten voeren hier niets uit — je ziet alleen wat er op Windows zou gebeuren. Instellingen worden niet bewaard.

Probeer de bubbel

Druk ergens op het bureaublad, sleep naar een vakje en laat los. Loslaten in het midden annuleert.

Druk en sleep op het bureaublad

Op Windows verschijnt de bubbel niet bij een gewone klik, maar bij een gebaar — zie hieronder.

Het gebaar

  1. Houd de rechtermuisknop ingedrukt en klik er dan met links bij.
  2. De glazen bubbel verschijnt rond je cursor, waar die ook staat.
  3. Beweeg naar een vakje en laat los om die actie uit te voeren.
  4. Loslaten in het midden sluit de bubbel zonder iets te doen.

Een gewone rechtsklik blijft gewoon werken: het contextmenu verschijnt zodra je de rechterknop loslaat zonder linkerklik.

Claude Code-inbox

Draaien er Claude Code-sessies die op je wachten? Dan krijgt het "Claude Code"-vakje een badge met het aantal. Kies je dat vakje, dan opent dit glazen venster: bovenin de vraag, eronder een typeveld. Je antwoord gaat via het klembord naar het juiste terminal- of editorvenster.

Ik heb de muishook aangepast zodat een gewone rechtsklik opnieuw wordt afgespeeld. Zal ik ook het rechts-slepen doorgeven, of laten we dat zoals het is?
Typ je antwoord… Verstuur

CursorBubble typt nooit blind: pas als het doelvenster écht op de voorgrond staat, gaan Ctrl+V en Enter eruit. Lukt dat niet, dan blijft je antwoord op het klembord staan om zelf te plakken.

Kant-en-klare .exe

GitHub Actions bouwt bij elke commit een self-contained CursorBubble.exe — geen .NET nodig. In de repo: Actions → de bovenste groene Build-run → onderaan bij Artifacts → CursorBubble downloaden en uitpakken.

Vanaf de broncode

Zelf bouwen

Met de .NET 8 SDK op Windows, in de map met CursorBubble.sln: dotnet run --project src/CursorBubble

Beide vragen een Windows-pc. Op je telefoon kan de app zelf niet draaien — WPF, de globale muishook en de acrylic-blur bestaan alleen op Windows.
